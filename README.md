# Assistente de Turismo RAG

Este projeto cria um sistema de perguntas e respostas sobre turismo utilizando RAG (Retrieval-Augmented Generation).

## Como usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/turismo-rag.git
   cd turismo-rag
   ```

2. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```

3. Configure a variável de ambiente do Pinecone:
   ```bash
   export PINECONE_API_KEY="sua_api_key"
   ```

4. Rode a aplicação:
   ```bash
   streamlit run app.py
   ```
